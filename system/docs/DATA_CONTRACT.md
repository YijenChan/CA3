# CA3 UI data contract

The local interface renders immutable artifacts generated by the pipeline
adapter.  Every displayed claim has one of four sources:

1. observed FMG/community records;
2. Lead or Assistant validated output;
3. deterministic controller/ledger state;
4. the final attack-summary projection.

The UI never turns textual similarity, LLM confidence, or ATT&CK context into a
forensic witness.  Identity-continuity edges are marked `retrieval_only` and
are not rendered as attack transitions.

## Round JSON

Each `round_*.json` contains the Campaign Snapshot, scheduled COI, retrieved
communities, admitted FMG edges, critical frontiers, cumulative IC assessment,
validated Lead proposal, optional typed Assistant task, validated verdict,
controller action, ledger delta, and scope request.

## Prompt JSON

Each `prompts/round_*.json` preserves the actual system/user messages, raw
response content, latency/usage fields, and round-local alias map.  These files
are intentionally separate from the compact UI copy so figure wording can be
adjusted without mutating the accepted scientific trace.

## Attack summary

`attack_summary_graph.json` is a summary projection of the controller-committed
witnessed backbone.  For this CADETS case it contains four raw events:

- public-service `RECVFROM` ingress to `nginx`;
- `SENDTO` callback;
- `nginx` writing `/tmp/vUgefal`;
- `master` executing `/tmp/vUgefal`.

Termination means the single-host upstream entry boundary is resolved.  It does
not claim that every later campaign behavior has been observed.
